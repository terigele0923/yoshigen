吉源商事 シンプルホームページ

■ 使用技術
- HTML
- CSS
- JavaScript

※ フレームワークは使っていません。
※ Bootstrap、jQuery、Laravel、WordPressは使っていません。

■ ページ構成
- index.html：トップ / LPページ
- company.html：会社紹介
- business.html：事業内容
- contact.html：問い合わせ
- css/style.css：デザイン
- js/main.js：スマホメニュー

■ デザイン
- 背景：白
- 文字：黒
- 強調色：赤

■ 修正が必要な仮情報
- 住所
- 電話番号
- メールアドレス
- 代表者名

■ 注意
問い合わせフォームは見た目だけです。
実際にメール送信するにはPHPなどの送信処理が必要です。
